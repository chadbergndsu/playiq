# Clip media (gitignored content)

This folder is intentionally empty in the **public** repository.

- Do **not** commit youth/student game film, roster posters, or anything that identifies minors.
- Keep local practice media on your machine or private storage only.
- Uploads in the app stay in browser IndexedDB — they are not pushed to git.

Placeholders may be added for product demos that use only non-identifying / licensed assets.
